# Recall R0 and R1 (#449, #438) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Log what recall pushes and which index calls each session pulls (R0), then backfill a digest for a session that ended without one (R1).

**Architecture:** R0 adds `vaultlib/recall_log.py` (stdlib and `vaultlib/state.py` only), which writes `system/logs/recall-<YYYY-MM>.jsonl`. `vault_index.py recall` writes the push line from counts `recall.build` returns; `memory_activity.sh` hands a Bash call that names `vault_index.py` to `system/scripts/recall_log.py pull`, which reads the frozen session state and skips the CLI's scope resolution. R1 has `memory_keep.sh` queue a `<id>.backfill` marker at `SessionEnd`; the intake tick turns the kept transcript into a redacted excerpt in `raw/inbox/.staging/` and runs the new headless command `digest-backfill` through the publish gate, then checks what it wrote.

**Tech Stack:** bash, jq, Python 3 stdlib (`shlex`, `hmac`), bats, pytest.

**Spec:** `docs/superpowers/archive/specs/2026-11-03-recall-r0-r1-design.md`

## Global Constraints

- One log file, `system/logs/recall-<YYYY-MM>.jsonl` (machine local time, as `usage-<YYYY-MM>.jsonl`); every line has `ts`, `kind` (`push`, `pull`, `backfill`) and `session`.
- Logs hold counts, note ids and paths only: no prompt text, no note text; `related` and `query` terms as a keyed SHA-256, first 16 hex digits, key at `system/logs/memory/recall.key` (mode 600) (Q8).
- Every log write is wrapped and swallowed: logging never changes recall's stdout or a hook's exit.
- No log line, marker or backfill for headless runs, Work Orders, subagents (`agent_id`) or Workcell sessions (`FOUNDRY_WORKCELL_SESSION=1`) (Q2).
- No new hook entry and no `install_hooks.sh` change in R0; the activity fast path runs no `jq` or `python3` for a Bash call that does not name `vault_index.py`.
- Core cap: `CORE_CAP=16480` (from 16,080 once #479 merged first; the spec's 16,250 was 15,850 + 400), raised once in PR 1, comment naming this spec (Q6). R0 measured 202 lines (15,837 to 16,039; the spec estimated 90), which leaves 211 for R1 to R5: PR 2 trims R1 toward 80 to 130 lines, or the owner accepts R2 to R5 sharing what is left (ledger ruling, Task 5).
- No new schema (core holds at 14).
- Bats ruling R1: no mid-test `!`, no `&&` assertion chains, no wall-clock timing assertions. Tests stub claude; the probes (Tasks 1 and 6) and the live acceptance run real claude in a `.scratch/` clone with the sandbox off.
- Template rule: no hostname, user path, remote URL, distro, account id, employer, client, codebase or people name. Fixtures use invented session ids and note names.
- One `changes/` file per PR, one `- Changed:` line each. The owner merges both PRs (hooks, headless runner, publish gate, redaction).
- Delivery: PR 1 = this plan and Tasks 1-5 (branch `feat/recall-r0`, build PR #480). PR 2 = Tasks 6-12 (branch `feat/recall-r1`, cut from master after PR 1 merges).

## Review Focus

1. A Bash command whose quoting `shlex` cannot parse (an unbalanced quote) still exits 0 and logs at most `sub`-only lines (Task 4 test `test_pull_survives_unbalanced_quotes`).
2. `vault_index.py` named only inside a note's text that a `show` prints (in `tool_response`, not in the command) logs nothing (Task 4 test `test_pull_ignores_a_command_without_the_script`).
3. A `--source` value Claude Code adds later never makes recall exit non-zero (Task 2 test `test_unknown_source_is_logged_as_given`).
4. A kept transcript line that is not JSON, or one over 2 MB, is skipped and the rest of the excerpt is built (Task 9 test `test_excerpt_skips_bad_and_huge_lines`).
5. A Stop digest that lands between the marker and the tick drops the marker with no run (Task 10 test `test_a_late_stop_digest_drops_the_marker`).

**Interfaces:**

- Produces: `recall_log.terms_hash(vault, text: str) -> str`: HMAC-SHA256 keyed by `system/logs/memory/recall.key` (32 random bytes, created with `os.open(..., O_CREAT | O_EXCL | O_WRONLY, 0o600)`, read back if it exists), of `" ".join(text.lower().split())`, first 16 hex.
- Produces: `recall_log.pull(vault, event: dict) -> list[dict]`: the records it wrote. `[]` when the session id fails `SID`, the event has `agent_id`, `tool_name != "Bash"`, or `system/logs/memory/sessions/<id>.json` is missing. Each record: `kind: "pull"`, `session`, `scope`, `partition` (from the state), `sub`, `terms`, `hits`, `paths`, `note`, `found` (absent values are `None`).
- Produces: `recall_log.main(argv=None) -> int`: `pull` reads the hook JSON on stdin and calls `pull`; always returns 0.
- `memory_activity.sh`: after the `printf` of the counter, `[[ "${FOUNDRY_WORKCELL_SESSION:-}" != 1 && "$input" =~ \"tool_name\"[[:space:]]*:[[:space:]]*\"Bash\" && "$input" == *vault_index.py* ]] || exit 0`, then `printf '%s' "$input" | timeout 3 "${BASH_SOURCE[0]%/*}/../scripts/recall_log.py" pull > /dev/null 2>&1`.

The parser (the signature does not fix it):
- Tokens: `shlex.shlex(command, posix=True, punctuation_chars=True)` with `whitespace_split = True`; on `ValueError`, `command.split()`. A token made only of `();<>|&` ends an invocation.
- An invocation starts at each token whose last path part is `vault_index.py`; `sub` is the next token. The argument is the first later token that is not an option, not the value of `--limit`, `--codebase`, `--type`, `--per-source` or `--budget-chars`, and not a partition name after `--partition`.
- `related`, `query`: `terms = terms_hash(arg)`. `show`, `backlinks`: `note = arg`. Other subs: `sub` only.
- Output, only when the command has exactly one invocation (else `hits` and `found` stay `None`): `stdout` is `tool_response["stdout"]` for a dict, the string itself for a string, else `""`. `related`: `--json` output (starts with `[`) gives each hit's `path`; else each line matching `^- .+ — (.+?\.md) \(`. `backlinks`: `--json` list, else each `- <path>` line. `hits = len(all paths)`, `paths = first 10`, `found = hits > 0`. `show`: `found = bool(stdout.strip())`. `query`: `hits = None`.
