# RCA-to-Jira Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A production error group gets an attended root-cause analysis in the Foundry, and its ticket reaches Jira only after the owner approves it (#106, phase 1).

**Architecture:**
- `/rca <raw/telemetry/note>` (`.claude/commands/rca.md`) runs the diagnosis procedure read-only. It writes an `rca` note (new schema and template) with a Ticket draft, and adds an `owed` Now line with `rca:<stem>` evidence.
- On each intake tick, `Intake.file_rcas()` reads `vaultlib/rca.pending()`:
  - a ticked line runs `rca_file.sh`, a confined session allowed only `createJiraIssue`, called once with arguments `rca.py` builds from the settings and the draft;
  - `rca.py` checks the session and writes the key back to the note and the Now line, under `run.lock`;
  - a dropped line marks the note rejected.
- A key file saved before the write-back keeps a retry from filing the same draft twice.
- Settings `rca_*` live in `/setup` 6c.

**Tech Stack:** bash, Python 3 (stdlib), bats 1.8.2, pytest.

**Spec:** `docs/superpowers/specs/2026-10-11-rca-design.md`

## Global Constraints

- Work on branch `feat/rca`. Commit there; do not push or open a pull request.
- New prose follows the Writing rules in `CLAUDE.md`. Template rule: no machine, employer or people names, and no account IDs (`EX`, `example.atlassian.net` are placeholders).
- Run the suites from the repository root with `TMPDIR=$PWD/.scratch/tmp GIT_CEILING_DIRECTORIES=$PWD/.scratch` (`mkdir -p .scratch/tmp` once), outside a sandbox. The gate is `system/scripts/verify_setup.sh`. Never run two gates at once.
- Bound tools: pytest (`test_rca.py`, `test_intake.py`, `test_schema_notes.py`), bats (`rca.bats`, `commands.bats`, `vault_integrity.bats`) and the gate.
- bats ruling R1: no mid-test `!`, no `&&` assertion chains, no wall-clock timing assertions.
- Commits use `git commit -F .scratch/<file>`.
- Every "Find" text below occurs exactly once in its file at that step. A "Create" step writes the whole file.

## Review Focus

- **Nothing reaches Jira without the owner's tick.** Only ticked lines with `rca:` evidence on a draft without a ticket are filed; a dropped line rejects. Tests: `test_pending_finds_ticked_and_dropped_drafts_only`, the intake cap test.
- **The filer's scope:** one call to the create tool with exactly the approved arguments; another tool, other arguments or a second call fails closed. Test: `test_the_session_check_reads_the_key_and_refuses_anything_else`, the bats refusal test.
- **Never filed twice:** a key saved before the write-back means a retry only writes back. Test: the bats "a ticket already created" test.
- **Off by default:** filing waits for `rca_project`; incomplete settings or a malformed draft exit 2 before any session. Tests: `test_rca_filing_is_off_without_rca_project`, `test_incomplete_settings_or_drafts_are_a_usage_error`.
- **`/rca` writes nothing outward and stays read-only on code.** Test: the `/rca` text test.

## Live check before merge

No test reaches the real Atlassian connector. With `rca_project` set to a test project, the owner runs `/rca` on one error-group note, ticks its Now line, and confirms the ticket appears and its key is written back to the note.

- Produces `Intake.file_rcas()`, run after `check_now`.
- Consumes `now.LINE`, `now.STAMP`, `now.read`/`write`, and `cli.set_scalar`.

````text
"""RCA-to-Jira (RCA spec §3.3): pending drafts, the filer's arguments, the session check and the write-back."""
import shutil

import pytest

from helpers import REPO, write
from vaultlib import now, rca

TODAY = "2026-10-11"
CONFIG = ('---\ntype: config\ntimezone: "America/Denver"\nhandoffs_site: "example.atlassian.net"\nrca_project: "EX"\n'
          'rca_labels: ["production-finding"]\n---\n')
DRAFT = ("## Ticket draft\n\n**Summary:** Orders fail when the reference is empty\n\n**Description:**\n"
         "Symptom: 409 on submit.\n\nRoot cause: `src/app/orders.py:42`.\n")


def note(vault, stem="2026-10-11-orders", partition="work", status="draft", ticket="", body=DRAFT):
    extra = f'ticket: "{ticket}"\n' if ticket else ""
    return write(vault, f"wiki/{partition}/rca/{stem}.md",
                 f'---\ntype: rca\ntitle: "Orders fail"\npartition: {partition}\ncreated_at: "{TODAY}"\n'
                 f'source: "raw/telemetry/a.md"\nrc_confidence: 4\nfix_confidence: 4\nstatus: {status}\n{extra}---\n'
                 f"# Orders fail\n\n## Root cause\n\nx\n\n{body}")


def prepare(vault, config=CONFIG):
    shutil.copytree(REPO / "system" / "templates", vault / "system" / "templates", dirs_exist_ok=True)
    write(vault, "system/config.md", config)


def line(vault, stem, mark=" ", partition="work"):
    now.add(vault, partition, "owed", f"Review RCA draft: {stem}", TODAY, evidence=f"rca:{stem}")
    path = vault / f"wiki/{partition}/Now.md"
    path.write_text(path.read_text().replace(f"- [ ] owed: Review RCA draft: {stem}", f"- [{mark}] owed: Review RCA draft: {stem}"))


def test_pending_finds_ticked_and_dropped_drafts_only(vault):
    prepare(vault)
    for stem, mark in (("a-ticked", "x"), ("b-dropped", "-"), ("c-open", " "), ("d-filed", "x")):
        note(vault, stem, status="filed" if stem == "d-filed" else "draft", ticket="EX-1" if stem == "d-filed" else "")
        line(vault, stem, mark)
    now.add(vault, "work", "owed", "Not an rca line", TODAY, evidence="EX-9")
    assert rca.pending(vault) == [("file", "work", "a-ticked"), ("reject", "work", "b-dropped")]


def test_arguments_come_from_the_settings_and_the_draft_only(vault):
    prepare(vault)
    note(vault)
    assert rca.arguments(vault, "work", "2026-10-11-orders") == {
        "cloudId": "example.atlassian.net", "projectKey": "EX", "issueTypeName": "Bug",
        "summary": "Orders fail when the reference is empty",
        "description": "Symptom: 409 on submit.\n\nRoot cause: `src/app/orders.py:42`.",
        "contentFormat": "markdown", "additional_fields": {"labels": ["production-finding"]}}


@pytest.mark.parametrize("config,body,reason", [
    (CONFIG.replace('rca_project: "EX"', 'rca_project: ""'), DRAFT, "rca_project"),
    (CONFIG.replace('"example.atlassian.net"', '"https://x"'), DRAFT, "handoffs_site"),
    (CONFIG, "## Fix\n\nnone\n", "Ticket draft"),
    (CONFIG, DRAFT.replace("**Summary:** Orders fail when the reference is empty", "**Summary:**"), "Summary"),
])
def test_incomplete_settings_or_drafts_are_a_usage_error(vault, config, body, reason):
    prepare(vault, config)
    note(vault, body=body)
    with pytest.raises(rca.Fail) as e:
        rca.arguments(vault, "work", "2026-10-11-orders")
    assert e.value.code == 2 and reason in e.value.reason


def stream(args, tool=rca.TOOL, calls=1, error=False, result=None):
    s = [{"type": "assistant", "message": {"content": [{"type": "tool_use", "id": "t0", "name": "ToolSearch", "input": {}}]}},
         {"type": "user", "message": {"content": [{"type": "tool_result", "tool_use_id": "t0",
                                                   "content": [{"type": "tool_reference", "tool_name": rca.TOOL}]}]}}]
    for n in range(1, calls + 1):
        s.append({"type": "assistant", "message": {"content": [{"type": "tool_use", "id": f"t{n}", "name": tool, "input": args}]}})
        s.append({"type": "user", "message": {"content": [{"type": "tool_result", "tool_use_id": f"t{n}", "is_error": error,
                                                           "content": "…"}]},
                  "tool_use_result": {"structuredContent": result if result is not None else {"key": "EX-7", "id": "1"}}})
    s.append({"type": "result", "subtype": "success", "is_error": False})
    return s


def test_the_session_check_reads_the_key_and_refuses_anything_else(vault):
    prepare(vault)
    note(vault)
    args = rca.arguments(vault, "work", "2026-10-11-orders")
    assert rca.extract(stream(args), args) == "EX-7"
    assert rca.extract(stream(args, result={"issue": {"key": "EX-8"}}), args) == "EX-8"
    for s, code in ((stream(args, tool="mcp__claude_ai_Atlassian__editJiraIssue"), 7),
                    (stream({**args, "summary": "something else"}), 7),
                    (stream(args, calls=2), 7),
                    (stream(args, error=True), 6),
                    (stream(args, result={"id": "1"}), 1)):
        with pytest.raises(rca.Fail) as e:
            rca.extract(s, args)
        assert e.value.code == code


def test_filed_writes_the_key_to_the_note_and_the_now_line(vault):
    prepare(vault)
    path = note(vault)
    line(vault, "2026-10-11-orders", "x")
    rca.filed(vault, "work", "2026-10-11-orders", "EX-7", TODAY)
    text = path.read_text()
    assert 'ticket: "EX-7"' in text and 'status: "filed"' in text
    assert "_(closed: filed EX-7 2026-10-11)_" in now.read(vault, "work")
    assert rca.pending(vault) == []


def test_rejected_sets_the_status(vault):
    prepare(vault)
    path = note(vault)
    rca.rejected(vault, "work", "2026-10-11-orders")
    assert 'status: "rejected"' in path.read_text()
````

  printf -- '---\ntype: concept\ntags: [now]\ncompiled_at: "2026-10-11"\npartition: work\n---\n# Now\n\n## Needs you\n- [x] owed: Review RCA draft: Orders fail (since 2026-10-11, rca:%s)\n\n## Waiting\n' "$STEM" \
    > wiki/work/Now.md

  ALERTS="system/logs/alerts_$(TZ=America/Denver date +%F).md"
  ARGS="$(system/scripts/rca.py args work "$STEM")"
}

# jira_says <tool> <args json> [key]: a session that loads the tool and calls it once.
jira_says() {
  {
    printf '{"type":"assistant","message":{"content":[{"type":"tool_use","id":"t1","name":"ToolSearch","input":{}}]}}\n'
    printf '{"type":"user","message":{"content":[{"type":"tool_result","tool_use_id":"t1","content":[{"type":"tool_reference","tool_name":"%s"}]}]}}\n' "$C"
    jq -cn --arg t "$1" --argjson a "$2" '{type: "assistant", message: {content: [{type: "tool_use", id: "t2", name: $t, input: $a}]}}'
    jq -cn --arg k "${3:-EX-7}" '{type: "user", message: {content: [{type: "tool_result", tool_use_id: "t2", content: "…"}]},
      tool_use_result: {structuredContent: {key: $k, id: "1"}}}'
    printf '{"type":"result","subtype":"success","is_error":false}\n'
  } > "$STUB_STREAM"
}

@test "an approved draft is filed once, and the key reaches the note, its Now line and the alerts" {
  jira_says "$C" "$ARGS"
  run "$RF" work "$STEM"
  [ "$status" -eq 0 ]
  [ "$output" = "EX-7" ]
  grep -qx 'ticket: "EX-7"' "wiki/work/rca/$STEM.md"
  grep -qx 'status: "filed"' "wiki/work/rca/$STEM.md"
  grep -qF '_(closed: filed EX-7 ' wiki/work/Now.md
  grep -qF '[rca] filed EX-7 for' "$ALERTS"
  grep -qxF -- "$C" "$STUB_ARGS"
  grep -qxF -- mcp__claude_ai_Atlassian__editJiraIssue "$STUB_ARGS"
}

@test "another tool or other arguments are refused, write nothing and alert once a day" {
  jira_says mcp__claude_ai_Atlassian__editJiraIssue "$ARGS"
  run "$RF" work "$STEM"
  [ "$status" -eq 7 ]
  jira_says "$C" "$(jq -c '.summary = "something else"' <<< "$ARGS")"
  run "$RF" work "$STEM"
  [ "$status" -eq 7 ]
  grep -qx 'status: draft' "wiki/work/rca/$STEM.md"
  [ "$(grep -c '\[rca\] Filing' "$ALERTS")" -eq 1 ]
}

@test "a ticket already created is only written back, never filed twice" {
  mkdir -p system/logs/rca
  printf 'EX-5\n' > "system/logs/rca/work-$STEM.key"
  run "$RF" work "$STEM"
  [ "$status" -eq 0 ]
  [ ! -e "$STUB_ARGS" ]
  grep -qx 'ticket: "EX-5"' "wiki/work/rca/$STEM.md"
  [ ! -e "system/logs/rca/work-$STEM.key" ]
}

@test "incomplete settings or a bad target exit 2 before any session" {
  sed -i 's/^rca_project: "EX"$/rca_project: ""/' system/config.md
  run "$RF" work "$STEM"
  [ "$status" -eq 2 ]
  [ ! -e "$STUB_ARGS" ]
  run "$RF" work ../escape
  [ "$status" -eq 2 ]
  run "$RF" work
  [ "$status" -eq 2 ]
}

"""RCA-to-Jira (RCA spec §3.3): which approved drafts to file, the filer's arguments, the check of its session, and the
write-back. The arguments come from the settings and the note's Ticket draft only; the key comes from the tool result."""
import json
import re
from pathlib import Path

from . import frontmatter, now as nowmod
from .cli import set_scalar
from .stream import blocks

TOOL = "mcp__claude_ai_Atlassian__createJiraIssue"
PROJECT = re.compile(r"^[A-Z][A-Z0-9_]{0,30}$")
KEY = re.compile(r"^[A-Z][A-Z0-9_]{0,30}-[0-9]{1,9}$")
SITE = re.compile(r"^[a-z0-9][a-z0-9.-]{0,200}$")
STEM = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._-]{0,120}$")
SUMMARY_MAX = 255
DESCRIPTION_MAX = 32000
PER_TICK = 3


class Fail(Exception):
    def __init__(self, code, reason):
        super().__init__(reason)
        self.code, self.reason = code, reason


def config(vault) -> dict:
    path = Path(vault) / "system" / "config.md"
    return (frontmatter.parse(path.read_text(encoding="utf-8")).data or {}) if path.is_file() else {}


def note_path(vault, partition: str, stem: str) -> Path:
    return Path(vault) / "wiki" / partition / "rca" / f"{stem}.md"


def pending(vault) -> list:
    """(action, partition, stem) for each Now line with rca:<stem> evidence that you ticked (file) or dropped (reject),
    whose note is still a draft without a ticket."""
    out = []
    for partition in nowmod.PARTITIONS:
        for line in nowmod.read(vault, partition).split("\n"):
            m = nowmod.LINE.match(line)
            ev = (m.group("evidence") or "") if m else ""
            if not ev.startswith("rca:") or m.group("mark") not in "xX-":
                continue
            stem = ev[4:]
            path = note_path(vault, partition, stem)
            if not STEM.match(stem) or not path.is_file():
                continue
            data = frontmatter.parse(path.read_text(encoding="utf-8")).data or {}
            if data.get("type") == "rca" and data.get("status", "draft") == "draft" and not data.get("ticket"):
                out.append(("reject" if m.group("mark") == "-" else "file", partition, stem))
    return out


def draft(text: str) -> tuple:
    """(summary, description) from the note's ## Ticket draft section."""
    body = frontmatter.parse(text).body
    section = re.search(r"(?ms)^## Ticket draft\s*$(.*?)(?=^## |\Z)", body)
    if not section:
        raise Fail(2, "the note has no ## Ticket draft section")
    m = re.search(r"(?ms)^\*\*Summary:\*\*[ \t]*(.*?)[ \t]*$\s*^\*\*Description:\*\*[ \t]*$(.*)", section.group(1))
    summary, description = (m.group(1).strip(), m.group(2).strip()) if m else ("", "")
    if not summary or "\n" in summary or len(summary) > SUMMARY_MAX:
        raise Fail(2, f"the Ticket draft needs a one-line **Summary:** of at most {SUMMARY_MAX} characters")
    if not description or len(description) > DESCRIPTION_MAX:
        raise Fail(2, "the Ticket draft needs a **Description:**")
    return summary, description


def arguments(vault, partition: str, stem: str) -> dict:
    """The createJiraIssue arguments, from the settings and the note only."""
    cfg = config(vault)
    site, project = str(cfg.get("handoffs_site") or ""), str(cfg.get("rca_project") or "")
    if not SITE.match(site):
        raise Fail(2, "handoffs_site is not set to a Jira site such as example.atlassian.net")
    if not PROJECT.match(project):
        raise Fail(2, "rca_project is not set to a Jira project key")
    labels = cfg.get("rca_labels") if isinstance(cfg.get("rca_labels"), list) else []
    summary, description = draft(note_path(vault, partition, stem).read_text(encoding="utf-8"))
    args = {"cloudId": site, "projectKey": project, "issueTypeName": str(cfg.get("rca_issue_type") or "Bug"),
            "summary": summary, "description": description, "contentFormat": "markdown"}
    if labels:
        args["additional_fields"] = {"labels": [str(x) for x in labels]}
    if cfg.get("rca_assignee"):
        args["assignee_account_id"] = str(cfg["rca_assignee"])
    return args


def _find_key(value):
    if isinstance(value, dict):
        if isinstance(value.get("key"), str) and KEY.match(value["key"]):
            return value["key"]
        for v in value.values():
            found = _find_key(v)
            if found:
                return found
    if isinstance(value, list):
        for v in value:
            found = _find_key(v)
            if found:
                return found
    return None


def extract(stream, args: dict) -> str:
    """The new issue's key, after checking the session called only the create tool, once, with exactly `args`."""
    calls, named, created, errors = {}, False, [], []
    for m in stream:
        if m.get("type") == "assistant":
            for b in blocks(m, "tool_use"):
                if b.get("name") not in ("ToolSearch", TOOL):
                    raise Fail(7, f"the session used an unexpected tool: {b.get('name')}")
                if b.get("name") == TOOL:
                    if b.get("input") != args:
                        raise Fail(7, "the session called the create tool with other arguments than the approved draft")
                    if any(c.get("name") == TOOL for c in calls.values()):
                        raise Fail(7, "the session called the create tool more than once")
                calls[b.get("id")] = b
        if m.get("type") == "user":
            for b in blocks(m, "tool_result"):
                call = calls.get(b.get("tool_use_id")) or {}
                content = b.get("content")
                if call.get("name") == "ToolSearch" and isinstance(content, list) and any(
                        isinstance(c, dict) and c.get("tool_name") == TOOL for c in content):
                    named = True
                if call.get("name") != TOOL:
                    continue
                if b.get("is_error"):
                    errors.append(json.dumps(content)[:200])
                    continue
                tur = m.get("tool_use_result")
                created.append(tur.get("structuredContent") if isinstance(tur, dict) else None)
    if errors:
        raise Fail(6, f"the connector returned an error: {errors[0]}")
    if not any(c.get("name") == TOOL for c in calls.values()):
        raise Fail(1 if named else 3, f"the session never called {TOOL}" if named else "no Atlassian connector reachable")
    key = _find_key(created[0]) if created else None
    if not key:
        raise Fail(1, "the create call returned no issue key")
    return key


def filed(vault, partition: str, stem: str, key: str, today: str) -> None:
    """Under run.lock: the note records the ticket, and its Now line's stamp names it."""
    path = note_path(vault, partition, stem)
    set_scalar(path, "ticket", key)
    set_scalar(path, "status", "filed")
    lines = nowmod.read(vault, partition).split("\n")
    for i, line in enumerate(lines):
        m = nowmod.LINE.match(line)
        if m and m.group("evidence") == f"rca:{stem}" and m.group("mark") in "xX":
            lines[i] = f"{nowmod.STAMP.sub('', line).rstrip()} _(closed: filed {key} {today})_"
    nowmod.write(vault, partition, "\n".join(lines))


def rejected(vault, partition: str, stem: str) -> None:
    set_scalar(note_path(vault, partition, stem), "status", "rejected")

#!/usr/bin/env python3
"""RCA-to-Jira helpers for rca_file.sh and the intake tick (RCA spec §3.3).

Usage: rca.py pending                          print "<file|reject> <partition> <stem>" per approved or dropped draft
       rca.py args <partition> <stem>          print the createJiraIssue arguments as JSON
       rca.py extract <partition> <stem>       check a filer session's stream on stdin; print the new issue key
       rca.py filed <partition> <stem> <key>   write the key back to the note and its Now line, under run.lock
Exit: 0 ok, 1 claude error or no key, 2 usage or incomplete settings or draft, 3 no connector, 4 run.lock busy,
6 connector error, 7 unexpected tool use or other arguments. A non-zero exit writes one reason line to stderr.
"""
import json
import sys
from pathlib import Path

VAULT = Path(__file__).resolve().parents[2]
sys.path.insert(0, str(VAULT / "system" / "scripts"))
from vaultlib import rca  # noqa: E402
from vaultlib.intake import Intake  # noqa: E402
from vaultlib.stream import messages  # noqa: E402


def target(partition: str, stem: str) -> tuple:
    if partition not in ("work", "personal") or not rca.STEM.match(stem) or not rca.note_path(VAULT, partition, stem).is_file():
        raise rca.Fail(2, f"no RCA note wiki/{partition}/rca/{stem}.md")
    return partition, stem


def main(argv) -> int:
    try:
        if argv[1:] == ["pending"]:
            print("".join(f"{a} {p} {s}\n" for a, p, s in rca.pending(VAULT)), end="")
        elif len(argv) == 4 and argv[1] == "args":
            print(json.dumps(rca.arguments(VAULT, *target(argv[2], argv[3]))))
        elif len(argv) == 4 and argv[1] == "extract":
            args = rca.arguments(VAULT, *target(argv[2], argv[3]))
            print(rca.extract(messages(sys.stdin.read()), args))
        elif len(argv) == 5 and argv[1] == "filed" and rca.KEY.match(argv[4]):
            intake = Intake(VAULT)
            with intake.lock("run.lock", timeout=120):
                rca.filed(VAULT, *target(argv[2], argv[3]), argv[4], intake.today())
        else:
            raise rca.Fail(2, "usage: rca.py pending | args <p> <stem> | extract <p> <stem> | filed <p> <stem> <key>")
    except rca.Fail as f:
        print(f"rca: {f.reason}", file=sys.stderr)
        return f.code
    except TimeoutError:
        print("rca: run.lock busy; nothing written", file=sys.stderr)
        return 4
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
