**🕑 Today so far:** the data file's `today:` line is the embed of the day's log, which the server fills during the day. Put a `## 🕑 Today so far` section just before `## 📝 Notes` holding that embed line verbatim (`![[<date>.today]]`, written with the `!`), then the `yesterday` line as `Yesterday the watch logged <its text>.` Write nothing else there: the log fills itself. When an existing briefing has no 🕑 Today so far section, add it before 📝 Notes.
